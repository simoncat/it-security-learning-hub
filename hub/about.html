    About this hub

    The HKSARG IT Security Learning Hub is a static learning aid for bureau and department staff. It is aligned to Baseline IT Security Policy [S17] version 8.2 and IT Security Guidelines [G3] version 10.2, issued by the Digital Policy Office in April 2025.

    Hub v0.1-MVP · Content aligned to S17 v8.2 / G3 v10.2 · Last reviewed: 2026-10-26

    How to use it

    1. New joiners follow fundamentals, then framework and accountability.
    2. Current staff filter by role, system lifecycle, and need.
    3. Read a decision aid before the long text. Open the source pages when you need the section itself.
    4. Order is S17, then G3, then Appendix C only for Tier 2 or Tier 3. Shall first. Not every word.

    Versions

    • Hub v0.1-MVP, last reviewed 2026-10-26.
    • S17 v8.2 and G3 v10.2, April 2025. Assumed if the PDFs were not re-checked for this build.

    Accessibility

    The target is WCAG 2.1 AA: text contrast, visible focus, a logical heading order, and keyboard access to the overview, filters, and quizzes. Pages are English only.

    What this hub will not do

    • No login, no staff roster, and no completion record on a server.
    • A tick is a private note in one browser. It is not evidence and not a signature.

    Learning aid only. Authoritative text remains S17, G3, Security Regulations, and B/D local policies.
