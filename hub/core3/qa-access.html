    Access, passwords, and privileged use

    Can I keep a colleague’s access until the project ends, even though they moved team?

    No. Access that no longer matches the job is removed or reduced when the job changes. Extend it only through a new request that names the task.

    The whole team uses one administrator password stored in our chat. Is that acceptable if we trust each other?

    No. Privileged access has to identify the person. Replace the shared password with named privileged accounts and stop posting secrets in chat.

    Our Tier 2 system has no MFA on the interactive admin logon because it would slow us down. Can we skip it?

    Appendix C expects MFA for interactive privileged logon on Tier 2 and Tier 3 where it is feasible. Inconvenience is not the same as infeasible. If it truly cannot be done, record the reason and the owner, and confirm the row in G3 Appendix C.
