Management support (DITSO support)

Anchor: G3 §5 and §7 themes. New joiners use this as the bridge out of fundamentals. Current staff use it to see the Shall items for this job. It is not a calendar.

About 45–60 minutes a day. Oversight fluency, not deep admin how-to.

Shall first. Appendix C rows apply only when the system is Tier 2 or Tier 3, and Tier 3 inherits Tier 2.

Not every-word — S17 first, then G3; deep-read Shall and App C; Should = implement whenever possible.

Reading order: S17, then the same-theme G3 section, then Appendix C if the system is Tier 2 or Tier 3.
