Management responsibilities and risk

Management names the roles, separates duties that should be separated, funds the work, and classifies systems so the controls match.

Not every-word — S17 first, then G3; deep-read Shall and App C; Should = implement whenever possible.

Reading order: S17, then the same-theme G3 section, then Appendix C if the system is Tier 2 or Tier 3.

ShallDEC-MGMT-01

Has this system been given a tier and an owner?

Classified protection means every system, including a shared service, gets a tier and controls to match. An owner is part of that, not a later nice-to-have.

Relevance
Management support and project staff at initiation, and again when the system changes role.
Applicability
Roles: IT security administrator / unit and Management support lead. System / LAN administrator and Application developer supply facts.Stages: 01 Project initiation, 06 Go-live, 08 Change.Tiers: Tier 1, Tier 2, Tier 3.
Prerequisites
The system has a name. Shared services are in scope, not exempt.
Implementation guidance
Ask for the tier and the information owner. If either is missing, record a gap. Do not invent the tier to make a form look finished.
Source
S17 §7 G3 §7

Shall App CDEC-MGMT-03

What extra management control appears at Tier 3?

Appendix C adds Tier 3 expectations for the risk framework and for keeping risk registers. Tier 3 also inherits Tier 2 Appendix C controls from other themes.

Relevance
Management support for an essential-service system.
Applicability
Roles: IT security administrator / unit and Management support.Stages: Any stage.Tiers: Tier 3.
Prerequisites
The tier is confirmed as Tier 3, or clearly marked as a proposal.
Implementation guidance
Confirm the row on the App C matrix and in G3 Appendix C. Baseline §7 still applies.
Source
G3 Appendix C S17 §7 G3 §7

ShouldDEC-MGMT-02

What should a risk decision look at?

Judge criticality with defence and safety, financial effect, government image, and interdependency, and with scope, severity, and how long the service can be down.

Relevance
Persons writing a one-page risk note.
Applicability
Roles: Management support and the security unit.Stages: 01 Project initiation, 02 Design, 08 Change.Tiers: Tier 1, Tier 2, Tier 3.
Prerequisites
You have a factual description of the system. You are not copying a generic sentence.
Implementation guidance
Use the department’s risk method. Keep the note short enough that the owner can accept or reject the remainder.
Source
S17 §7 G3 §7 S17 §6
