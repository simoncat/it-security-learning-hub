When cryptography applies

Use cryptography when the classification or the channel requires it. There is no Appendix C block on §12. The baseline still applies.

Not every-word — S17 first, then G3; deep-read Shall and App C; Should = implement whenever possible.

Reading order: S17, then the same-theme G3 section, then Appendix C if the system is Tier 2 or Tier 3.

ShallDEC-CRYPTO-01

Do I need cryptography for this data?

Use it when the information is classified, when it crosses a channel you do not control, or when it is stored where unauthorised persons could read the media.

Relevance
Developers and administrators choosing a channel or a store.
Applicability
Roles: System / LAN administrator and Application developer, with IT security administrator / unit assuring.Stages: 02 Design, 04 Build/Implementation, 07 Operations.Tiers: Tier 1, Tier 2, Tier 3.
Prerequisites
You know the classification and whether the path is trusted.
Implementation guidance
Protect data in transit and at rest as G3 §12 and your local standard require. Do not invent an algorithm in this hub. Use the standard your B/D or the practice guide names.
Source
S17 §12 G3 §12

ShallDEC-CRYPTO-02

Is unprotected wireless good enough?

No, when government information needs protection. An open wireless network is a common way classified or internal information is exposed.

Relevance
Anyone connecting a laptop, and administrators who provide wireless.
Applicability
Roles: All roles.Stages: Any stage.Tiers: Tier 1, Tier 2, Tier 3.
Prerequisites
You know you are about to put government information on that network.
Implementation guidance
Use the approved network. If you are unsure the wireless is approved, do not send the information.
Source
S17 §12 G3 §12 S17 §15
