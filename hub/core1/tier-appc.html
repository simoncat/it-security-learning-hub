Tier and when Appendix C applies

Tier 1 takes the baseline. Tier 2 and Tier 3 also take Appendix C. Tier 3 inherits every Tier 2 Appendix C control. You do not finalise a tier on your own.

Not every-word — S17 first, then G3; deep-read Shall and App C; Should = implement whenever possible.

Reading order: S17, then the same-theme G3 section, then Appendix C if the system is Tier 2 or Tier 3.

ShallDEC-TIER-01

Can I stamp the tier myself?

No. Classified protection is a management responsibility. Propose the impact if you are asked, then confirm with the information owner or the DITSO route your B/D uses.

Relevance
Project staff and administrators who are about to write a tier on a slide.
Applicability
Roles: All roles.Stages: 01 Project initiation, 02 Design, 08 Change.Tiers: Tier 1, Tier 2, Tier 3.
Prerequisites
You can describe what the system does and what fails if it is lost, changed, or exposed.
Implementation guidance
Write impact, interdependency, and whether an essential service is involved. Mark the tier unconfirmed until the owner says otherwise. A checkbox in this hub is not a classification.
Source
S17 §7 G3 §7 S17 §4 G3 §4

Shall App CDEC-TIER-03

Does Appendix C apply to this system?

Appendix C applies when the system is Tier 2 or Tier 3. It does not apply to an ordinary Tier 1 system. The baseline S17 and G3 sections still apply underneath.

Relevance
Anyone about to skip, or about to demand, extra controls.
Applicability
Roles: All roles that operate or assure those systems.Stages: Any stage.Tiers: Tier 2, Tier 3.
Prerequisites
The tier is confirmed, or you are explicitly working a proposal and have labelled it as a proposal.
Implementation guidance
Open the App C matrix, keep every Tier 2 row if the system is Tier 2 or Tier 3, and add Tier 3-only rows only for Tier 3. Confirm the wording in G3 Appendix C.
Source
G3 Appendix C S17 §4 G3 §4

Shall App CDEC-TIER-04

Does Tier 3 drop the Tier 2 Appendix C controls?

No. Tier 3 includes Tier 2. Every Tier 2 Appendix C control also applies to Tier 3, and then the Tier 3-only controls apply as well.

Relevance
Staff reading an empty cell and treating it as an exemption.
Applicability
Roles: Security unit and management support in particular.Stages: Any stage.Tiers: Tier 3.
Prerequisites
You are looking at the matrix row by row, not at a single empty cell.
Implementation guidance
On the matrix, read the Tier 2 column as still in force for Tier 3. An empty Tier 3 cell does not cancel a Tier 2 control on that row or on any other row.
Source
G3 Appendix C

ShouldDEC-TIER-02

Which tier description am I closest to?

Tier 1 is the ordinary baseline. Tier 2 is a system whose failure or disruption would seriously affect government operations, or could cause public turmoil or catastrophe. Tier 3 is a Tier 2 system tied directly to an essential service.

Relevance
Staff preparing a question for the owner, not staff issuing the classification.
Applicability
Roles: All roles.Stages: Any stage.Tiers: Tier 1, Tier 2, Tier 3.
Prerequisites
You have a named system. You have not yet treated a guess as final.
Implementation guidance
Read S17 §4 and G3 §4 in the source pages. Take the paraphrase only as a prompt for the question you will ask the owner.
Source
S17 §4 G3 §4
