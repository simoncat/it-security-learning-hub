Operations, backup, patch, and monitoring

Operations security covers procedures, malware protection, backup, logging, vulnerabilities, and change in the running environment.

Not every-word — S17 first, then G3; deep-read Shall and App C; Should = implement whenever possible.

Reading order: S17, then the same-theme G3 section, then Appendix C if the system is Tier 2 or Tier 3.

ShallDEC-OPS-01

Do I need a backup I can actually restore?

Yes when the service must be recoverable. A copy you have never restored is a hope, not a backup.

Relevance
System administrators and service owners.
Applicability
Roles: System / LAN administrator leads.Stages: 06 Go-live, 07 Operations.Tiers: Tier 1, Tier 2, Tier 3.
Prerequisites
You know which service and which data must come back.
Implementation guidance
Follow G3 §14 and the local backup standard. For Tier 2 or Tier 3, check the Appendix C operations rows before you sign off.
Source
S17 §14 G3 §14

ShallDEC-OPS-02

A vulnerability or a missing patch is open. What is the Shall?

Known vulnerabilities are handled through the departmental process: patch, mitigate, or accept with an owner. Silent delay is not a process.

Relevance
Administrators and the security unit.
Applicability
Roles: System / LAN administrator and IT security administrator / unit.Stages: 07 Operations, 08 Change.Tiers: Tier 1, Tier 2, Tier 3.
Prerequisites
You have an advisory or a scan result, and a system it applies to.
Implementation guidance
Use the local patch process. If the system is Tier 2 or Tier 3, Appendix C expects timely patching and visibility to the DITSO when a fix slips. Confirm that row in G3 Appendix C.
Source
S17 §14 G3 §14

Shall App CDEC-OPS-03

Which operations extras apply at Tier 2?

Appendix C adds Tier 2 operations controls, including off-site backup, capacity planning, an end-of-support plan ahead of the deadline, and patching with DITSO visibility if the fix slips. Tier 3 inherits these.

Relevance
Administrators of Tier 2 and Tier 3 systems.
Applicability
Roles: System / LAN administrator and IT security administrator / unit.Stages: 07 Operations.Tiers: Tier 2, Tier 3.
Prerequisites
The tier is confirmed.
Implementation guidance
Walk the App C matrix row for operations. Do not treat this card as a substitute for the appendix wording.
Source
G3 Appendix C S17 §14 G3 §14

Shall App CDEC-OPS-04

What monitoring extra applies only at Tier 3?

Appendix C adds Tier 3 monitoring of a security-monitoring class, drawing on more than one source, around the clock. This is on top of the Tier 2 operations controls, which still apply.

Relevance
Security unit for an essential-service system.
Applicability
Roles: System / LAN administrator and IT security administrator / unit.Stages: Any stage.Tiers: Tier 3.
Prerequisites
The system is confirmed Tier 3.
Implementation guidance
Confirm the monitoring row in G3 Appendix C and name the service that provides it. A daytime mailbox is not the same control.
Source
G3 Appendix C G3 §14
