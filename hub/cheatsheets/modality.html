Shall, Should, May, and the reading flow

Source pointers: S17 §4.2 · G3 §4.2 · G3 §2.3

Print this page. It is a one-page reminder, not a copy of the policy.

WordMeaningWhat you do
ShallMandatory requirement. Must do.Deep-read these lines. They are not optional.
ShouldBest practice. Implement whenever possible.Do it unless you can say why not.
MayDesirable best practice.Use it when it helps. It does not cancel a Shall.

Reading flow

  1. Security Regulations set the government security floor.
  2. S17 states the IT security policy: the what.
  3. G3 states the guidelines: the how, in the same section numbers.
  4. Practice guides add procedure. They live on ITG InfoStation.
  5. Local B/D policy can be stricter.
  6. Appendix C adds controls only for Tier 2 and Tier 3. Tier 3 includes every Tier 2 App C control.
Not every-word. Skim the section, then deep-read Shall lines, role-critical rows, and App C when the tier requires it.

Learning aid only. Authoritative text remains S17, G3, Security Regulations, and B/D local policies.
